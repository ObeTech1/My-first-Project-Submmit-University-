# Summit University Website

## Project Overview
Summit University is a multi-page university website built to provide visitors with information about the institution, its academic programmes, admission process, and contact details.

The website is designed to provide a clear, accessible, and user-friendly experience for prospective students, current students, and visitors.

## Project Objectives
- Build a complete multi-page university website.
- Practise semantic HTML5.
- Apply CSS3 for styling and responsive layouts.
- Create functional navigation between pages.
- Develop accessible forms and structured content.
- Build a professional and consistent website design.

## Website Pages

### 1. Home — `index.html`
The homepage introduces Summit University and includes:
- University logo and navigation.
- Hero section with a background image.
- University introduction.
- Reasons to study at Summit University.
- Featured academic programmes.
- Call-to-action for prospective students.
- Footer.

### 2. About Us — `about.html`
This page introduces the university and explains its identity.

It should include:
- University history and background.
- Vision and mission statements.
- Core values.
- Academic philosophy.
- Leadership or management information.
- Campus and facilities information.

### 3. Courses — `courses.html`
This page provides information about academic programmes.

It should include:
- Available courses and programmes.
- Faculties and departments.
- Programme descriptions.
- Course duration.
- An HTML table for programme information.
- Links to admissions.

### 4. Admissions — `admissions.html`
This page explains how prospective students can apply.

It should include:
- Admission requirements.
- Application procedures.
- Required documents.
- Application form.
- Programme selection.
- Relevant instructions for applicants.

### 5. Contact Us — `contact.html`
This page provides ways to communicate with the university.

It should include:
- University address.
- Email address and phone number.
- Office opening hours.
- Contact form.
- Social media links.

## Technologies
- HTML5
- CSS3

JavaScript and CSS frameworks will not be used in this project.

## Development Requirements

### HTML Requirements
- Correct HTML document structure.
- Semantic HTML elements.
- Proper heading hierarchy.
- Working internal navigation links.
- Images with descriptive alt attributes.
- Lists and tables.
- Forms with labels and appropriate input types.
- Accessible and meaningful page structure.

### CSS Requirements
- CSS selectors and specificity.
- Box model.
- Typography and colour combinations.
- Margin and padding.
- Flexbox and CSS Grid.
- Positioning.
- Hover effects and pseudo-classes.
- Transitions and transforms.
- CSS variables.
- Media queries and responsive design.

## Project Rules
1. Write the HTML for all pages before moving to CSS.
2. Do not use Bootstrap, Tailwind, or other CSS frameworks.
3. Do not use JavaScript.
4. Keep the code organised and readable.
5. Use consistent navigation across all pages.
6. Make the website responsive on desktop, tablet, and mobile devices.
7. Research and solve problems independently before requesting assistance.

## Completion Criteria
The project will be considered complete when:

- All five pages are properly structured.
- Navigation works across all pages.
- Images display correctly.
- Forms and tables are properly structured.
- Semantic HTML is used appropriately.
- CSS styling is consistent across the website.
- The website is responsive.
- There are no major HTML validation errors.
- The developer can explain the code and techniques used.
